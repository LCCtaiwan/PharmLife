# PharmLife v0.2 深度版計畫書

## 產品定位

PharmLife 是以台灣藥師職涯為背景的選單式人生模擬遊戲。它借用職涯模擬器的清楚成長骨架、養成遊戲的立即回饋，以及人物驅動敘事的事件鏈；自己的核心特色是「取捨」。

每次選擇都可能同時改善與傷害不同面向。升遷也許增加收入與聲望，卻降低體力與家庭時間；創業可能累積資產，也可能帶來負債；Burnout、國考落榜、轉職失敗與離婚都不是單純扣分，而是通往新內容的岔路。

## Brainstorming Summary

### 三個設計支柱

1. 有控制但不完全可控：行動由玩家選，事件、檢定與世界進度由版本化 Seed 決定。
2. 性格由選擇形成：玩家不直接選「工作狂」，而是多次選擇後被遊戲辨認出人格。
3. 失敗本身是內容：失敗會改變 flags、關係與後續事件池，不產生空白回合。

### 一局的節奏

- 18–24 歲：學生篇與國考教學。
- 24–35 歲：建立能力、重要 NPC 與第一條職涯 Build。
- 35–50 歲：跳槽、管理、創業、家庭與中年危機。
- 50 歲後：傳承、半退休、財務自由或繼續工作。
- 結束：依人生資料產生稱號、成就、時間線與分享卡。

### UI 方向

- 手機優先的「藥盒／處方標籤」視覺語言：米白紙張、深墨綠、螢光薄荷與警示珊瑚色。
- 主畫面一次只呈現一個主要決策，維持拇指可操作尺寸。
- 隱藏精確代價；選擇前顯示傾向，選擇後才揭示實際變化。
- 桌面版採左側人物狀態、中間事件／行動、右側生涯摘要三欄；手機版折疊成分頁。

## 內容層級

### 能力與人格

八能力皆為 0–100，UI 顯示 S–E 評級。人格為 -100–100 的連續軸，透過累積選擇形成特質標籤並影響事件權重、檢定與結局。

### NPC

核心 NPC 橫跨學生、職場與家庭。NPC 具有好感、信任、利益三種關係值，並隨年份轉職、升遷、創業或退休。玩家錯過某條線時，NPC 的世界仍會前進。

### 事件

事件資料包含：id、分類、標題、敘事、條件、權重、冷卻、NPC、選項、檢定、成功／失敗效果、flags 與後續事件。選擇不顯示完整數值，避免遊戲退化成試算表最佳化。

### 經濟

金額以萬元為單位。每年結算收入、基本支出、家庭支出、利息與資產報酬。玩家可買房、還債、投資創業、展店或接受盤讓。薪資為遊戲化指數，不等同即時市場資料。

## Milestones

- M0：可重現的年度核心迴圈。
- M1：學生、國考與第一份工作完整垂直切片。
- M2：八大職涯、升遷、跳槽與專屬事件。
- M3：人格、NPC、事件鏈、家庭與世界進度。
- M4：Burnout、資產負債、創業、成就與多結局。
- M5：存讀檔、人生卡、手機 UI、部署與完整驗收。

里程碑僅用於內部切片；v0.2 的交付標準是 M0–M5 全部完成。
